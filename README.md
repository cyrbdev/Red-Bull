# Red Bull Website

A Red Bull-inspired website project focused on modern web design, visual presentation, and brand identity.

## About the Project

This website was developed at **Lancaster County Career & Technology Center (LCCTC)** as part of the **Interactive Media & Web Design** program.

The project explores how visual design, website structure, and branding can be combined to create a digital experience inspired by an established brand.

This is an educational project and is not affiliated with or endorsed by Red Bull.

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling and visual design

## Project Focus

- Brand-inspired website design
- Visual hierarchy and page layouts
- Content organization
- Front-end development
- User interface design

## Project Goals

The goal of this project was to strengthen my front-end development and web design skills while applying the principles learned at LCCTC.

I focused on creating a website that reflects a recognizable brand identity through layout, typography, and visual presentation.

## Getting Started

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
